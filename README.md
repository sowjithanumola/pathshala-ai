
# Pathshala AI

**Learn anything. In any language. Anywhere.**

> Built for the CodeBenders ACE Builders Hackathon 2026.

Pathshala AI is a modern, responsive, offline-capable learning workspace designed for students and independent learners. Built using React, TypeScript, Vite, and Firebase, it brings essential educational tools together in one unified platform.

With ten dedicated learning modules, Pathshala AI aims to make education more accessible, interactive, personalized, and convenient — helping learners study at their own pace and in their preferred language.

## 🎓 Core Features — 10 Learning Modules

Pathshala AI is organized into ten core modules, accessible directly through its learning workspace.

| # | Module | Description |
|---|---|---|
| 1 | **Dashboard** | Central learning overview with quick access to important activities and learning tools. |
| 2 | **Learn** | A dedicated space for structured learning content, educational modules, and lessons. |
| 3 | **Language Lab** | Language-focused learning tools designed to support multilingual learning and linguistic practice. |
| 4 | **Visual Learning** | Visual explanations and diagram-based learning resources to make complex concepts easier to understand. |
| 5 | **Quizzes** | Interactive knowledge assessments with scoring and feedback. |
| 6 | **Library** | A centralized space for accessing and organizing learning resources and study materials. |
| 7 | **Notebook** | A personal workspace for creating, storing, and organizing study notes. |
| 8 | **Calendar & Timetable** | Learning schedules and timetable management to help organize study activities. |
| 9 | **Progress** | A learning progress overview to help users monitor their educational journey. |
| 10 | **Profile & Settings** | Personal account settings, application preferences, and profile management. |

## ⚙️ Technology Stack

Pathshala AI uses modern web technologies to deliver a responsive and maintainable learning experience.

| Technology | Purpose |
|---|---|
| **React** | Component-based user interface development. |
| **TypeScript** | Type safety and maintainable application code. |
| **Vite** | Fast development environment and production bundling. |
| **Tailwind CSS** | Utility-first styling and responsive UI development. |
| **PostCSS** | CSS processing and optimization. |
| **Firebase** | Backend services, including authentication and Firestore database integration. |
| **Service Worker** | Offline capabilities and application caching. |
| **Local Storage / IndexedDB** | Local data persistence where implemented. |
| **Vercel** | Application hosting and deployment. |

### 💡 Our Vision

As a duo consisting of **Sowjith Anumola and Sanjith**, our vision is to build an accessible, modern, and flexible educational workspace.

We aim to bring multiple learning tools into one application, helping students and independent learners:

- Learn through structured educational content.

- Understand concepts through visual explanations.
- Test their knowledge through interactive quizzes.
- Organize resources and personal notes.
- Manage study schedules.
- Monitor their learning progress.

Our goal is to make learning more organized, accessible, and engaging through technology.
