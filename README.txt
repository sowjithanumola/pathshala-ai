Pathshala AI Download App Button

Included:
- src/components/DownloadAppButton.tsx

How to use:
1. Copy DownloadAppButton.tsx into your project's src/components folder.
2. In the navbar/header component, import it:
   import DownloadAppButton from "./components/DownloadAppButton";
   (Adjust the relative path if your navbar is in a different folder.)
3. Add <DownloadAppButton /> where you want the button to appear.
4. If lucide-react is not installed, run:
   npm install lucide-react
